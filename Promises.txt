1) Promises:
	i) A promise is an object that represents a value that will 	be available in future
	ii) It uses for async operations like api calls, db 	queries, file reading, timers etc
2) Why:
Problems in JS:
	1) JS runs one line at a time
	2) Slows tasks like db,api takes time
	3) JS does not wait for them, so normal return fails
	EX:
	function getData(){
		setTimeout(()=>{return "Data";},2000)	
	}
	const res = getData();
	c.log(res);

	Output:
	undefined

3) Promises solve this:
	function getData(){
		return new Promise((resolve) => {
			setTimeout(() => {
				resolve("Data");
			},2000);
		);
	}
	getData().then((result) => {c.log(result););	

	Output: After 2 seconds, Data

4) The 3 states of a promise:
	Every promise has:
	i) pending -> work is happening
	ii) fulfilled -> success
	iii) rejected -> error

5) Using .then, .catch
	promise
  	.then((data) => {
    		console.log("Success:", data);
  	})
  	.catch((error) => {
    		console.log("Error:", error);
  	});

6) Promise Chaining:
	getUser()
  	.then(user => getOrders(user.id))
  	.then(orders => console.log(orders))
  	.catch(err => console.log(err));
	
	Each .then() returns a promise

7) Promise.all() method implementation manually
	function myPromiseAll(promises){
		return new Promise((resolve,reject)=>{
			const results = [];
			let c = 0;
			promises.forEach((promise,idx)=>{
				Promise.resolve(promise)
				.then((value)=>{
					results[idx] = value;
					c+=1
					if (c==promises.length)
						resolve(results);				})
				.catch((error)=> {reject("Error"););
			});
		});
	}
	const p1 = new Promise(res => setTimeout(() => res("A"), 1000));
	const p2 = new Promise(res => setTimeout(() => res("B"), 2000));
	const p3 = new Promise(res => setTimeout(() => res("C"), 1500));

	myPromiseAll([p1, p2, p3])
  	.then(result => console.log(result))
  	.catch(err => console.error(err));

	output: ["A", "B", "C"]

What happens if fails:
	Ex: const p2 = Promise.reject("Error!");
	
	output: Error!


***** Why promises over async-await *****
Why can use async-await, it is built on top of promises.
	async function login() {
  		const user = await getUser();
  		const token = await generateToken(user);
  		return token;
	}

But, when You MUST Use Raw Promises:

1) Parellel execution:
	const p1 = getUser();
	const p2 = getOrders();
	const results = await Promise.all([p1, p2]);
2) Event-based handling:
	Sometimes chaining is cleaner:
	
	fetch(url)
  	.then(res => res.json())
  	.then(data => console.log(data));
3) Process utilities:
	Like promise.all, promises.race, promises.any, promises.settled etc

*******Methods********
1) Promise.all():
	Runs multiple promises in parallel.
	Resolves when all promises succeed,Rejects if any promise fails
	EX 1:
	let p1 = Promise.resolve("Task1 done");
	let p2 = Promise.resolve("Task2 done");
	let p3 = Promise.resolve("Task3 done");
	Promise.all([p1, p2, p3])
	.then(result => {
	    console.log(result);
	});
	Output:
	["Task1 done", "Task2 done", "Task3 done"]

	EX: If one fails
	let p1 = Promise.resolve("Task1");
	let p2 = Promise.reject("Task2 failed");
	Promise.all([p1,p2])
	.catch(err => console.log(err));
	Output:
	Task2 failed

2) promise.allSettled():
	Waits for all promises to finish, regardless of success or failure.
	Returns status of each promise.
	EX: let p1 = Promise.resolve("Success");
	let p2 = Promise.reject("Failed");
	Promise.allSettled([p1,p2])
	.then(result => console.log(result));
	Output:
	[
		 { status: 'fulfilled', value: 'Success' },
		 { status: 'rejected', reason: 'Failed' }
	]

3) Promise.race():
	Returns the first promise that settles (success or failure).
	Ex:
	let p1 = new Promise(resolve => setTimeout(() => resolve("First"),1000));
	let p2 = new Promise(resolve => setTimeout(() => resolve("Second"),2000));
	Promise.race([p1,p2])
	.then(result => console.log(result));
	Output:
	First

4) Promise.any()
Returns the first successful promise.
If all promises fail -> it throws an error.
EX:
let p1 = Promise.reject("Error1");
let p2 = Promise.resolve("Success");
let p3 = Promise.resolve("Another success");
Promise.any([p1,p2,p3])
.then(result => console.log(result));

Output:
Success
-> If all fails, AggregateError
