Functions Types:
1) Named function:
	function greet() {
		return "hello";
	}
	console.log(greet())

2) Anonymous function:
	A function that does not have a name. 
	👉It is usually assigned to a variable or used as a callback.
	Since it has no name, it cannit be called directly.
	i) Assigned to a variable:
		const greet = function(){
			console.log("Anan func");
		}
		greet()
	ii)  Callback:
	setTimeOut(function() {
		console.log("Executed after 1 second");	
	},1000)

3) Function expression:
	When you assign a function to a variable, the function can then
	can be used by calling that variable.
	ex:
	const add = function(a,b) {
		return a+b;
	};
	console.log(add(10,20))

👉Difference between anonymous funtion and function expression:
	1) A function expression can be anonymous
	2) But a function expression does not have to be anonymous.
	Ex:
	1) Anonymous function expression
		const greet = function() {
			console.log("Hello");
		}
	2) Named function expression:
		const greet = function sayHello(){
			console.log("Hello");
		}
		
4) Arrow function(ES6):
	A new way to write functions using the => syntax.
	Ex:
	const square = n => n*n
	console.log(square(n));
	
	👉They are shorter and do not have their own this binding, which
	makes them useful in some cases.
	Ex: Normal function❌
	const obj={
		value: 10,
		show: function() {
			function inner(){
				console.log(this.value);
			}
			inner();
		}
	};
	obj.show();
	Output:
	undefined.
	Because inner() is a normal function.
	Ex: Arrow function✅
	const obj = {
		value: 10,
		show: function() {
			const inner = () => {
				console.log(this.value);
			};
			inner()
		}
	}
	Output: 10
	Because arrow functions do not create their own "this".
	Instead, they use "this" from the surrouding scope.
	
	👉Arrow functions do not have their own "this" binding.
	It means they do not create this, they reuse "this" from 
	where they defined.
	
5) Immediately Invoked Function Expression(IIFE)
These functions are executed immediately after their definition.

	(function() {
		console.log("This runs immedaitely");
	})();

6) Callback functions:
	A callback function is passed as an argument to another func
	and is executed after the completion of that function.
	function num(n, callback){
		return callback(n);
	}
	const double = (n) => n*2;
	console.log(num(5,double));

7) Constructor function:
	function Person(name,age){
		this.name=name;
		this.age=age;
	}
	const user = new Person("Prashanth",22);
	console.log(user.name);

8) Async function
	Functions that can handle async tasks.
	Declared with async, they return a promsise.
	
	async function fetchData() {
		return "Data fetched";
	}
	fetchData().then((res) => console.log(res));
	
	Async arrow function:
	const greet = async () => {
		return "Hello";
	}
	greet.then((res) => console.log(res));
